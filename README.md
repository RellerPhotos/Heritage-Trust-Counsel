# Heritage Trust Counsel

A responsive informational website for Heritage Trust Counsel, built with React, TypeScript, Vite, and CSS.

## Local development

```bash
npm install
npm run dev
```

## Before public launch

- Verify the attorney biography, education, bar admission, and professional history before adding credentials.
- Confirm the firm's office address and preferred contact details.
- Connect the enquiry form to an approved secure form/email service. The current form prepares an email in the visitor's email application; it does not submit to a server.
- Have California attorney advertising, professional responsibility, privacy, and disclaimer language reviewed by the firm.
- Replace or license photography as appropriate and confirm all image usage rights.
- Add a privacy policy and any required accessibility/legal notices.
